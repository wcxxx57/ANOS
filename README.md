# ANOS

#### 介绍
基于RISC-V架构的从0到1的小型内核实现

#### 环境要求
- Ubuntu 22.04.5 LTS
- RISC-V工具链
- QEMU模拟器
- Git版本控制

#### 编译运行

```bash
# 编译内核
make all

# 在QEMU中运行
make run

# 调试模式运行
make debug

# 清理构建文件
make clean
```
